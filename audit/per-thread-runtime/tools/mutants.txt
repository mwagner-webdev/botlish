# Mutants of the per-VM and per-thread runtime state
# (audit/per-thread-runtime/tools/mutate.tcl; PER-THREAD-RUNTIME-STATE-
# MILESTONE-1.md, "Mutation testing"): the Vm-owned context area, the
# Vm-owned program metadata, the per-thread stack-guard records, and the
# thread-local runtime state that must never outlive or cross a Vm.
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   !! DETECTOR ...    the detectors meant to kill it (one at least), each
#                      KIND:NAME -- rust-lib:TEST and rust-bin:TEST (a Rust
#                      test whose path contains TEST), native_stack:CHECK
#                      (a check of native/tests/native_stack.rs), FILE:TEST
#                      (tcltest TEST of tests/FILE, a -match pattern)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant is KILLED only when one of its own detectors fails (or does not
# complete); a crash of an unrelated test never counts. Lines starting with
# # outside an edit are comments.
#
# Not here, with the reason:
#   * "Release another VM's context-owned affine resource": no runtime code
#     releases context state (CONTEXT-OWNED-AFFINE-STATE-MILESTONE-1.md: an
#     installed context's members live as long as its Vm, and nothing
#     releases them at the end). The only way a Vm reaches another's
#     context-owned handle is a shared area: ctx-process-wide-area and
#     ctx-first-vm-area below, whose detectors see it.
#   * "Share a collection backing between VMs": a backing is reached only
#     through its header, a heap object of one Vm; sharing one needs a
#     shared area or a stale root, which the mutants below are.
#   * "Share a mutable runtime cache without synchronization": no such
#     cache exists to mutate (the transfer plans are the Vm's, the table-
#     hash key a OnceLock); the census records each process-wide item.
#   * "Destroy program metadata while a VM still references it": a Vm holds
#     an Arc of its program; no safe edit frees it early.
