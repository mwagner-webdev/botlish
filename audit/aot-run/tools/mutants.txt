# Mutants of -aot-run (AOT-RUN-MILESTONE-1.md): the driver's aot-run
# command (native/src/aotrun.rs), native::aotRun (native/native.tcl) and
# main.tcl's -aot-run and JIT boundary. Each is a deliberate bug, written as
# exact source replacements (the replaced text occurs exactly once);
# audit/aot-run/tools/mutate.tcl applies each to a private copy, rebuilds
# the driver and runs the detectors: the driver's aot_run unit tests and
# tests/aot-run.test. A %% line names the hosts whose code a mutant
# changes (none: every host).
#
# The format: "@@ NAME DESCRIPTION", an optional "%% HOST ...", then for
# each edit "## FILE" and "<<<<" OLD "====" NEW ">>>>".
