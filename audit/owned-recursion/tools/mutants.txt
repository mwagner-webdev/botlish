# Mutants of the recursive-ownership analysis (audit/owned-recursion/tools/
# mutate.tcl; OWNED-RECURSION-DECLARATION-SUMMARY-MILESTONE-1.md, "Mutation
# testing"): each a deliberate bug in hir/ownership.tcl, the drop descriptor
# walk it feeds (hir/affine.tcl), the struct checks that read it
# (hir/structs.tcl) or the shared fixpoint (hir/summaries.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Lines starting with # outside an edit are comments.
#
# Not mutants (equivalent, and why):
#   * "an edge's crossing taken from the walk's last step instead of any":
#     a walk crosses once it crossed (Walk's CROSSED only grows), so the
#     last step's flag is the path's.
#   * "a verdict asked during the affinity summary's fixpoint remembered":
#     nothing asks for one there (the affinity summary reads IsAffine, never
#     the recursion), so Recursion's guard never fires today; the provisional
#     facts that do arise -- a fixpoint's own -- are late-met-left-at-bottom's.
#   * "a non-affine state explored on": everything it reaches is
#     unrestricted too (an affine component would make it affine), so no
#     bad component is reachable through it; only the counters change.
