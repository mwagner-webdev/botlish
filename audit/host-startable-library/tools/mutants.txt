# Mutants of host-startable application libraries, cross-target link plans
# and Android C-binding generation (audit/host-startable-library/tools/
# mutate.tcl; RN-HOST-STARTABLE-APPLICATION-LIBRARY-MILESTONE-1.md, "Mutation
# testing"): the application's admission and header, manifest and public
# names (native/library.tcl), the entry dispatch (native/lower.tcl), the
# runtime's entry and its thread state (native/src/runtime/library.rs,
# thread.rs), the ABI fingerprint (aotimage.rs), the forwarder
# (codegen/library.rs), the cross-target link plan (codegen/aot.rs,
# native/library.tcl), and the generator's android-aarch64 configuration
# (tools/cheader/toolchain.tcl).
#
#   @@ NAME DESCRIPTION
#   !! TEST ...        the tests that must kill it (al-* application-
#                      library.test, at-* android-target.test, cb-*
#                      c-bindgen.test, nl-* native-library.test; rust:FILTER
#                      the driver's cargo tests matching FILTER)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant is killed only by a detector its !! line names failing; a mutant
# that does not build is NOT-BUILT, never killed. Lines starting with #
# outside an edit are comments.
