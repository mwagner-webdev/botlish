# Mutants of Botlish-owned threads and the cross-thread transport
# (audit/threads/tools/mutate.tcl; BOTLISH-OWNED-THREADS-AND-CROSS-THREAD-
# ACTORS-MILESTONE-1.md, "Mutation testing"): the runtime's thread registry
# and transport (native/src/runtime/thread.rs), the Linux driver's
# per-loop state (packages/event_loop_linux/native/event_loop_linux.c), the
# compiler's thread-entry rules (hir/threads.tcl, hir/contexts.tcl) and the
# library (stdlib/thread.bot, stdlib/actor/remote.bot, core/transfer.tcl).
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   !! DETECTOR ...    the detectors meant to kill it (one at least), each
#                      KIND:NAME -- rust-lib:TEST (a Rust test whose path
#                      contains TEST), FILE:TEST (tcltest TEST of
#                      tests/FILE, a -match pattern)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant is KILLED only when one of its own detectors fails (or does not
# complete: a mutant that leaves a call or a loop waiting forever is killed
# by the run's timeout). Lines starting with # outside an edit are comments.
#
# Not here, with the reason:
#   * "Join returns before the OS thread exited" (wait_ended without its
#     JoinHandle join): the window is a few microseconds after the entry's
#     end, so th-abi-loops sees it only sometimes; a detector that kills it
#     every time would need a hook in the runtime.
#   * "Share a heap object between VMs": no code path hands one VM's value
#     to another -- every crossing is transfer bytes (std::transfer's own
#     mutants, audit/value-transfer, kill a codec that keeps a reference).
