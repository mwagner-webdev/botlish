# Mutants of semantic value identity and std::immutable_map
# (audit/value-identity/tools/mutate.tcl; REPRESENTATION-INDEPENDENT-VALUE-
# IDENTITY.md, "Mutation testing"): the families the milestone brief names,
# each a deliberate bug in the identity declaration's checks, its HIR text,
# the runtimes' equality and hashing of an identity, the witness predicates,
# the frozen table engine (stdlib/ordered_table.bot), std::immutable_map,
# freezing (stdlib/mutable_map.bot) or the relational contracts of
# `reordered`.
#
#   @@ NAME DESCRIPTION
#   %% tests FILE ...      (optional) test files run first for this mutant
#   ## FILE
#   <<<<                   (or `<<<< all`: replace every occurrence, at
#   text to replace         least one; plain `<<<<` must occur exactly once)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
#
# Brief mutants with no non-equivalent mutant in this representation:
#
#   * "equality trusts a bucket's hash" natively, and the native set
#     construction deduplicating by hash alone: the native buckets are the
#     keyed table hash's (SipHash-1-3, 64 bits, under the process key), so
#     a wrong answer needs two unequal entries whose keyed hashes collide
#     -- no test can arrange one without the key, and a test key would test
#     only that key. The Tcl buckets are the public hash's, whose collision
#     corpus (audit/hashable/data) gives the Tcl mutants below their
#     detector (tcl-bucket-trusts-hash, tcl-set-dedup-trusts-hash); the
#     native equality's bucket probe compares the entries (entry_equal) on
#     the same rule, and native-bucket-ignores-value is its mutant.
#   * "the Equatable witness is the hash predicate" (witness
#     hir::types::HashClass for Equatable): core::value::incomparable and
#     core::hashing::unhashable are the same list today, so a type is
#     equality-total exactly when it is hash-total, and the two witnesses
#     agree on every type. The mutant becomes non-equivalent, and must be
#     added, the day a kind is comparable but not hashable.
#   * "freeze aliases the mutable map": an ImmutableMap holds Lists, which
#     are immutable values; no mutation of the source MutableMap can reach
#     them (MutableVector's logical copies, MUTABLE-VECTOR.md), so there is
#     no aliasing representation to mutate into. The declaration check that
#     keeps an identity struct free of mutable components is
#     identity-mutable-admitted's.
