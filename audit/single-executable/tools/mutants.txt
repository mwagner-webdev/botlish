# Mutants of the single-file compiler's packaging of the system linker
# (audit/single-executable/tools/mutate.tcl; SINGLE-EXECUTABLE-FFI-MILESTONE-1.md):
# single/package.tcl's archive contents and build id, single/main.tcl's
# installation and linker choice; and of its own Tcl library
# (SINGLE-EXECUTABLE.md, "How it is built"): single/basekit.c's startup
# without TCL_LIBRARY, and single/main.tcl's script search. The same format
# as audit/native-aot/tools/mutants.txt:
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Not here: a partial archive installed under its final name (the write is
# not atomic): no smoke test can race a first run reliably. Nor the Tcl
# module path left as tm.tcl makes it (single/main.tcl's `::tcl::tm::path
# remove`): Tcl reads it only for a package a script requires that no
# pkgIndex.tcl provides, and the compiler requires none (only Tcl itself),
# so no run of it can tell.
