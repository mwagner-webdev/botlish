# Mutants of the standalone Android SDL3 2048 application, its packages and
# its generator (audit/android-sdl3-2048/tools/mutate.tcl;
# RN-BOTLISH-ANDROID-SDL3-2048-PACKAGE-MILESTONE-1.md, "Mutation testing"):
# the 35 defects the milestone names, in its order -- the shared game logic
# (game2048_play, the React Native facade), the application loop
# (examples/android-sdl3/2048/app.bot), its UI and input (board.bot,
# sdlscreen::gesture), the native lifetime (botlish_android's SDL_main shim
# and manifest templates, sdlscreen's teardown), the packaging (the
# generator's checks and copies, the package manager's tools command).
#
#   @@ NAME DESCRIPTION
#   !! TEST ...        the tests that must kill it (as-* of
#                      tests/android-sdl3-2048.test, et-* of
#                      tests/external-tools.test)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Static detectors check source and distribution invariants (the game's one
# source, the shim's contents, the order of SDL's teardown); the others run
# the code: the pure modules on the interpreter, both applications under the
# Linux host shaped like SDL's Android bootstrap, the generator against
# damaged inputs. A mutant is killed only by a detector its !! line names
# failing. Lines starting with # outside an edit are comments.
