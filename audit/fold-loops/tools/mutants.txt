# Mutants of FOLD-LOOPS-MILESTONE-1.md (audit/fold-loops/tools/mutate.tcl):
# each a deliberate bug in folding loops -- an intermediate collected,
# replaced by `continue`, yielded as unit or a List by `break` or
# exhaustion, never replaced; an initial value evaluated before the loop's
# operands or its error swallowed; a type without its fixpoint, conflicts
# ignored or restated; the intermediate visible outside its fold; a fold
# credited with its domain's length; an affine intermediate accepted; a
# fold's body value taken for discarded; the initial value uncharged, not
# lowered, not printed; `fold` a reserved word -- in the parser, HIR, core IR
# and the evaluator, the Tcl compiler or native lowering.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments. Update a mutant's text when the code it mutates changes,
# keeping it a mutant of the same rule.
