# Mutants of the numeric/text boundary (audit/numeric-text/tools/mutate.tcl;
# NUMERIC-TEXT-BOUNDARY-MILESTONE-1.md): deliberate bugs in an Int's text
# both ways, Float64 rounding and a DecimalRounded value's text -- each in
# the Tcl runtime (core/) and in the native runtime (native/), which must
# be killed separately -- and in the front end's precision elaboration and
# static check (hir/decimal.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/ is a native
# mutant: mutate.tcl rebuilds the native backend for it. Lines starting with
# # outside an edit are comments.

# ---------------------------------------------------------------------------
# Int -> String (core/inttext.tcl)

@@ int-drops-minus the Int formatter drops the minus sign
## core/inttext.tcl
