# Mutants of the compilation target boundary (MACOS-AARCH64-MILESTONE-2.md;
# audit/target-model/tools/mutate.tcl): each a deliberate bug that lets one
# target's meaning be taken for another's -- the target table
# (core/cabi.tcl), platform module resolution and the HIR's recorded target
# (surface/modules.tcl), the interchange check (hir/cabi.tcl,
# hir/interchange.tcl), the cache (surface/cache.tcl), NIR's target line
# (native/lower.tcl) and the driver's host check and C convention selection
# (native/src). None mutates what Cranelift owns (register assignment, stack
# placement, extension): only the compiler's choice of the convention.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments. A mutant editing native/src rebuilds a private copy of the
# native backend. Update a mutant's text when the code it mutates changes,
# keeping it a mutant of the same rule.
