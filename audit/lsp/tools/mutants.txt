# mutants.txt -- the language server's mutants (tools/mutate.tcl;
# LSP-MILESTONE-1.md, "Mutation testing").
#
# Format: "@@ NAME DESCRIPTION" starts a mutant; "%% FILE ?PATTERN...?"
# names the test file that states its rule (tests/lsp.test when absent) and
# the tests of it that state it (tcltest -match patterns; every test when
# absent): each mutant must be killed by a focused test; "## FILE" names the
# file its next edits change; each edit is "<<<<", the exact text to replace
# (occurring once), "====", its replacement, ">>>>". Update a mutant's text
# when the code it mutates changes, keeping it a mutant of the same rule.

@@ length-in-characters a frame's Content-Length counts characters, not bytes: a non-ASCII message is framed too short
%% tests/lsp.test lsp-frame-split-anywhere lsp-proto-non-ascii
## lsp/transport.tcl
<<<<
    return "Content-Length: [string length $bytes]\r\n\r\n$bytes"
====
    return "Content-Length: [string length [encoding convertfrom utf-8 $bytes]]\r\n\r\n$bytes"
>>>>
