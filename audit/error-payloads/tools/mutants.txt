# Mutants of payload-bearing errors (audit/error-payloads/tools/mutate.tcl;
# ERROR-PAYLOADS.md): the mutants the milestone brief names (item 87), each
# a deliberate bug in the frontend (surface/lower.tcl), resolution
# (hir/resolve.tcl), the error descriptors (hir/errordecls.tcl), ownership
# (hir/affine.tcl), the coroutine contract (hir/coroutines.tcl), Core IR
# lowering (hir/lower.tcl), the Tcl runtime and compiler (core/value.tcl,
# core/evaluator.tcl, compiler/compiler.tcl), native lowering
# (native/lower.tcl) or the native runtime (native/src/runtime/).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
