Tool: audit/generic-predicate-proof-loss/tools/compiletime.tcl (see its header for the columns):
  range   hir::range::analyze wall time (all its Fixpoint calls plus rangerec.tcl's solve)
  pass    wall time inside the result-narrowing NarrowRounds calls (knob 1), summed over the
          analyze's Fixpoint calls. A converged pass's last round doubles as Fixpoint's final
          recompute (which knob 0 runs separately), so this is NOT the pass's net cost
  nir     native::nir wall time (prepareHir, specialization, this analysis, every other analysis,
          NIR emission)
  dRange  (median range 1 - median range 0) / median range 0
  fixpoints  per Fixpoint call at knob 1: instances:attempted/converged/rounds (Fixpoint state
          resultNarrow; analyze re-runs Fixpoint after pinning self-recursive summaries, hence two
          entries for bench/fib)
  AI      AnalyzeInstance calls made by one hir::range::analyze, knob 0 -> knob 1 (counted in a
          separate untimed run); "extra AI" = the per-instance walks the pass adds, net of the final
          recompute it replaces
Medians of N alternating runs (knob order 0,1 on even iterations, 1,0 on odd), minimum in
parentheses, milliseconds.

MACHINE LOAD / NOISE: measured on a shared 4-CPU machine while two full test-suite runs were in
progress (load average 3.7 -> 5.0 during these runs). Wall times are therefore noisy: across the 16
programs whose analysis work is provably identical at both knobs (same AnalyzeInstance count, see
the AI column), per-program dRange ranges from -3.9% to +4.6% in pass A and from -4.5% to +13.7% in
pass B (csv_geometric: +1.4% in A, +13.7% in B, identical work). Treat any per-program range delta
within about +/-14%, and any nir delta within a few %, as noise. The work counts (fixpoints, AI) are
exact and deterministic.

== Extra AnalyzeInstance rounds per program (exact, deterministic) ==
program                          instances  result-narrowing rounds   extra AnalyzeInstance rounds   AI calls 0 -> 1

every other program (16 of 17)    2 .. 59   1 (converged) per Fixpoint call   0                      identical
  (bench/fib: two Fixpoint calls, 1 round each; every pass in the corpus converged, none hit the
  budget.) A pass of R rounds that converges costs R-1 extra AnalyzeInstance rounds: its converged
  round analyzes every instance under exactly the committed facts and is reused as the final
  recompute. The only extra work of a 1-round pass is one RangeNarrow per result summary plus the
  change test -- not measurable here.

== Summary ==
* bench/refined-checks (the only program whose facts change): +1 AnalyzeInstance round (+29 calls,
  +10.8%). hir::range::analyze median +5.4 ms (+7.9%, pass A), +8.8 ms (+12.8%, pass B), +7.2 ms
  (+10.8%, pass C n=15) on ~67 ms; the pass itself takes 11.2-12.6 ms for its 2 rounds, i.e. ~6 ms
  per round, matching the one extra round. Whole native::nir: 385.1 -> 399.9 (A), 384.9 -> 392.7
  (B), 391.3 -> 390.1 (C) ms -- an expected ~+6 ms (~+1.5%) that is inside the noise.
* The other 16 programs: identical AnalyzeInstance counts; the pass runs 1 round that replaces the
  final recompute. Sum of range medians (excluding refined-checks) 496.7 -> 499.5 ms (+0.6%, A),
  500.9 -> 510.8 ms (+2.0%, B, mostly csv_geometric's noisy +4.9 ms; sum of minimums 474.9 -> 475.8,
  +0.2%); sum of nir medians 1866.2 -> 1853.0 (A), 1895.5 -> 1886.7 (B): no measurable change.
* Whole corpus, sum of native::nir medians: 2251.3 -> 2252.9 ms (A), 2280.3 -> 2279.5 ms (B).
* Cost bound: a pass that converges in R rounds adds R-1 rounds; one that does not converge adds
  its whole budget (its facts are discarded and the final recompute still runs). Each round is one
  AnalyzeInstance per used instance (the same unit M9's narrowing loop costs); the budget is
  Fixpoint's own roundBudget (4 * instances + 16) unless resultNarrowRoundLimit overrides it, and
  it applies to every Fixpoint call analyze makes (up to 1 + maxRecursivePasses = 3).
