# Mutants of the storage lifetime facts (hir/lifetime.tcl,
# STORAGE-LIFETIME-FACTS-MILESTONE-1.md; audit/storage-lifetime/tools/
# mutate.tcl): deliberate breaks of one rule each -- an edge of the control-
# flow graph, a liveness use, a containment constraint, an escape sink, a
# summary's field, a region's test. Each must be killed by
# tests/storage-lifetime.test, by one of the tests its `!!` line names (the
# test that states the rule it breaks), or, where `!!` names `fuzz`, by the
# independent oracle (fuzz.tcl, two seeds). Most are unsound breaks (a fact
# claimed that does not hold); the precision ones say so.
#
#   @@ NAME DESCRIPTION
#   !! TEST ...
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
