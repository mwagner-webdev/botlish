# Mutants of paths and the synchronous filesystem (audit/filesystem/tools/
# mutate.tcl; WINDOWS-X86-64-MILESTONE-7.md, "Mutation testing"): deliberate
# breaks of path syntax, lossless names, ownership, completion, failure
# paths, authority and the platform rule. Each must be killed by
# audit/filesystem/tools/fuzz.tcl or tests/filesystem.test. A mutant of code
# only one host runs (a `%% TARGET ...` line after its header) is SKIPPED on
# every other host, never counted as killed.
#
#   @@ NAME DESCRIPTION
#   %% TARGET ...                      (optional)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
