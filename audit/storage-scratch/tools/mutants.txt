# Mutants of compiler-managed scratch storage (STORAGE-COMPILER-MANAGED-
# SCRATCH-MILESTONE-1.md; audit/storage-scratch/tools/mutate.tcl): one
# broken rule each -- of the storage-use plan (hir/storageplan.tcl), its
# realization in native lowering (native/lower.tcl's "Scratch storage"), the
# storage provider (native/src/runtime/scratch.rs), the collector's
# treatment of scratch storage (heap.rs), the code generator's request and
# destination (codegen/clif.rs), the NIR protocol (nir.rs), and the three
# lifetime facts the integration fixed (hir/lifetime.tcl). Each must be
# killed by a detector its `!!` line names: a test of
# tests/scratch-storage.test (ss-...) or tests/storage-lifetime.test
# (sl-...), the differential fuzzer (fuzz) or the Rust tests (rust).
#
# One mutant considered is not here because no program we could write
# kills it: an instruction at a use of a String's binding taken as the
# site's even where the use runs in a deeper loop (native/lower.tcl's
# ScratchLoopOf check).
# Lowering materializes a binding that a deeper loop reads before that loop
# (eagerly, at the binding), never inside it, so the check never rejects an
# instruction today; it stays as a guard for a lowering that would defer
# across a loop (the report, section 19).
#

#   !! DETECTOR ...
#   ## FILE

#   text to replace (must occur exactly once in FILE)
