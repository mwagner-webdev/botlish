# Mutants of CONSUMED-FOLD-INTERMEDIATES-MILESTONE-1.md
# (audit/consumed-folds/tools/mutate.tcl): deliberate breaks of the rules
# that let a fold's intermediate be consumed instead of copied at every
# iteration's entry (hir/mutvec.tcl, "Consumed fold intermediates"): no
# `continue` or bare `break` of the fold after the iteration may have given
# the intermediate's header away (FoldExitsClean, FoldWalk, GivesHeader),
# every value the fold binds it to exclusive (FoldIncoming and the
# elaboration's wraps), and the precision those rules buy (a consumed
# fold's value is fresh, an `if`'s branches and a struct literal's fields
# are positions of their own). Each must be killed by
# tests/consumed-fold-intermediates.test, by one of the tests its `!!` line
# names: an unsound mutant by a value the copying elaboration does not give
# (cfi's eight outcomes disagree, or the value differs), a lost precision
# by the HIR or the native copy counters.
#
#   @@ NAME DESCRIPTION
#   !! TEST ...
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
