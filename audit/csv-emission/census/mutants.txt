# The CSV emitters' mutation census (CSV-EMISSION-VALIDATION-MILESTONE-1.md,
# section 12): each mutation applied alone to a private copy of
# examples/dfa/csv, every emitter module compiled, then run
# (audit/csv-emission/tools/census.tcl). A mutation changes an emitter,
# never a declared recognizer.
#
#   @@ NAME FILE EXPECT CLASS DESCRIPTION
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#   (more blocks, applied in order)
#
# EXPECT is the static verdict: the diagnostic kinds the compiler must
# report (EMIT-..., comma-separated; it may report more, for the claims that
# compose with the mutated one), or `accepted`. CLASS is what the census
# must find:
#
#   static          rejected, and a run shows an invalid trace (the
#                   ordinary examples already do)
#   static-latent   rejected, the ordinary examples' runs are valid, an
#                   adversarial run shows an invalid trace
#   unprovable      rejected, and no run finds an invalid or wrong output:
#                   correct code the checker cannot certify (a precision
#                   limit, never reported as a bug)
#   guard           accepted; a run fails with the emitter's declared error
#                   where the reference completes: a run-time guard stops
#                   the mistake before it writes anything wrong
#   guard-latent    the same, the ordinary examples unaffected
#   semantic        accepted; every trace is grammatical, but outputs are
#                   the wrong values (the independent oracle's round trips)
#   outside         accepted; every trace is grammatical and every value
#                   right, but something outside the claim is wrong (here:
#                   a source's final value)
