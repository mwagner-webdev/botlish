# Mutants of the android-aarch64 target (audit/android-aarch64-target/tools/
# mutate.tcl; ANDROID-AARCH64-TARGET-SUPPORT-MILESTONE-1.md, "Mutation
# testing"): each a deliberate bug of the target model, cross-target
# emission, the toolchain link, runtime identity, the native library's
# contract or distribution.
#
#   @@ NAME DESCRIPTION
#   !! TEST ...        the tests of tests/android-target.test meant to
#                      detect it (one failing is a kill)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments. A mutant that edits native/src rebuilds the copy's native
# backend; one that edits the runtime also changes the Android runtime
# archive the tests' fixture builds from the copy.
