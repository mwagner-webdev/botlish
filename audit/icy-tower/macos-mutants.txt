# Mutants of the Icy Tower macOS integration (ICY-TOWER-MACOS-MILESTONE-1.md,
# "Mutation testing"; audit/icy-tower/mutate.tcl -macos 1, on an Apple
# Silicon Mac): each a plausible defect of the port -- the build, the link
# plan, the binding, the entry program, the game's native boundary -- in the
# format of audit/icy-tower/mutants.txt (audit/golden/tools/mutants.txt),
# with one more line per mutant, which that format ignores:
#
#   ?? DETECTOR REGEX
#
# the check that must kill it and the text its failure must show (a Tcl
# regular expression): a mutant is killed only when that detector fails for
# that reason -- never because the mutant did not build when the detector is
# not the build, never because a runner did not allow a case (an
# ENVIRONMENT-BLOCKED case kills nothing). Detectors:
#
#   build         build-macos.sh fails (its checks: the dependencies against
#                 sdl3.pc, the binding's provenance, the link plan, the
#                 Mach-O's LC_MAIN and libraries, or the link itself)
#   abi           abi-check.py of the staged package against SDL3's headers
#   output        the executable's standard output and error (--help; an
#                 unknown video driver's report)
#   session:CASES macos-session.py's CASES (comma-separated) on the
#                 mutant's executable and probe build: a case FAILED with a
#                 failing check matching REGEX
#   app:CASES     macos-session.py app's CASES on the mutant's executable,
#                 assembled into Icy Tower.app by the tree's package-macos.sh
#                 and signed ad hoc by its release.py, launched through
#                 LaunchServices (ICY-TOWER-MACOS-APP-MILESTONE-1.md): a case
#                 FAILED with a failing check matching REGEX
#   relocate      the staged application moved and built again by
#                 Botlish.app alone
#   failed-build  the build run again with an archive holding no SDL3: it
#                 must fail and leave the previous executable as it was
#
# FILE is a path of the repository, or @binding/PATH: a file of the generated
# macos-aarch64 binding (a private copy of it, given to build-macos.sh as
# ICY_TOWER_BINDING_FROM). The game's rules have their own mutants
# (mutants.txt, killed by golden.bot); these leave the rules alone.
#
# Not here, with the reason: the LC_MAIN reservation itself (the driver's
# link arguments: audit/native-aot's main-thread mutants, MAIN-THREAD-
# STARTUP-MILESTONE-1.md; build-macos.sh's LC_MAIN check is what the two
# startup mutants below meet), and a GC-stress-only failure (no game-level
# change fails only under GC stress; the collector's own mutants are
# audit/native-stack's and the native harnesses').
