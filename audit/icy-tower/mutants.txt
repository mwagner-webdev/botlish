# Mutants of the Icy Tower vertical slice's rules (audit/icy-tower/mutate.tcl;
# ICY-TOWER-VERTICAL-SLICE-1.md, "Mutation evidence"): each a plausible bug
# in examples/games/icy-tower/'s pure modules -- the milestone brief's list
# first (collision ignores the descending condition, the camera follows
# downward, gravity's sign reversed, the platform removal threshold wrong,
# the score decreasing, restart keeping a stale velocity), then ones the
# rules' own decomposition suggests. Format (audit/golden/tools/mutants.txt):
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Every mutant must still apply and be killed by examples/games/icy-tower/
# golden.bot: a failed test, or a suite that no longer compiles.
