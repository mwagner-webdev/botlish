# Mutants of FOLD-VIRTUAL-STRUCT-STATE-MILESTONE-1.md
# (audit/fold-virtual-struct-state/tools/mutate.tcl): deliberate breaks of
# the rules that let a fold's struct intermediate be carried as independent
# field registers -- the shape fact (hir/escape.tcl's FoldShape, RefShape),
# the slot's eligibility (its sources, its captures, the no-loss rule), the
# fold as a recognized construction, the field-wise share of a copying
# fold's entry copy, and native lowering's one back-edge move, break and
# materialization. Each must be killed by tests/fold-virtual-struct-state.test,
# by one of the tests its `!!` line names: a value-changing mutant by an
# outcome that differs between the eight configurations (or from the pinned
# value), a lost precision by the fold-slot decisions, the struct census or
# the allocation and copy counters.
#
#   @@ NAME DESCRIPTION
#   !! TEST ...
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
