# The warning manifest (REFACTOR-WARNINGS-CLEAN.md): every warning the corpus
# is expected to carry after the warning-driven refactor, each with the
# obstruction that keeps it from closing on today's surface. The gate
# (audit/refactor/tools/gate.tcl, CI job `warning-gate`) asserts that the
# observed warnings are exactly these: a new warning anywhere, an entry that
# no longer fires, or a drifted location fails it. Every other program
# compiles under -warnings error.
#
# The manifest only shrinks on proof: an entry leaves when its finding is
# closed (converted, annotated, merged or marked) and the closing is verified
# (behavior probes or expected outputs; audit/refactor/tools/probe.tcl,
# expect.tcl). It grows only by a re-audit that finds something new.
#
# Format (gate.tcl's header has it in full):
#
#   program PATH | rejected PATH CODE | fails PATH CODE -- OBSTRUCTION
#     CODE LINE:COL TAG -- OBSTRUCTION      (an expected finding in PATH)
#
# TAG is H1 or H2 (the milestone's two hypotheses) or none.
#
# The obstructions, by name (the report has the evidence for each):
#
#   char->text   the value is a single character that must become text
#                (an operand of str::concat, a String result, a table of
#                text): Botlish has no character-to-text construction
#                (no str::of_char, no append of a UnicodeChar to a String),
#                and the only literal-free spelling slices it out of a longer
#                literal, which keeps the one-character String at run time
#                and only hides it from a literals-only check.
#   classifier   the character is also consumed by a String-taking
#                classifier (str::is_tcl_alnum / str::is_tcl_alpha) in the
#                same predicate or uniform predicate contract
#                (Fn{args: [str]}), so it is a one-character String there;
#                comparing it as a character means decoding that String
#                again (str::length(c) == 1 and c.char_at(0) == '_').
#   index-proof  the natural character spelling's str::char_at index is not
#                proven in range by today's completion proof.
#   test-datum   a test datum whose length 1 is the case's subject.
#   core-ir-roundtrip
#                the closing (a `-> list` result annotation) is a source fact
#                core IR cannot carry, and the program is a fixture of the
#                check that its HIR is what analysis of its core IR derives.
