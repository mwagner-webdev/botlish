# Mutants of std::mutable_map and std::mutable_set
# (audit/mutable-map/tools/mutate.tcl; ORDERED-MUTABLE-MAP-SET.md, "Mutation
# testing"): the mutants the milestone brief names (item 51), each a
# deliberate bug in the table engine (stdlib/ordered_table.bot), the
# collections (stdlib/mutable_map.bot, stdlib/mutable_set.bot), the
# runtimes they rely on or the compiler's lowering of them; then mutants of
# the general compiler seams this milestone added (place parameters, the
# loop protocol, MutableVector index proofs, opaque equality refusals).
#
#   @@ NAME DESCRIPTION
#   %% tests FILE ...      (optional) test files run first for this mutant
#   ## FILE
#   <<<<                   (or `<<<< all`: replace every occurrence, at
#   text to replace         least one; plain `<<<<` must occur exactly once)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
#
# Brief mutants with no non-equivalent mutant in this representation:
#
#   * "replacement changes stored key unexpectedly": no program can tell
#     two equal Hashable values apart. A Hashable type's values have total
#     equality and one representation each (Float64's negative zero is
#     admitted as zero; a DecimalRounded is not Hashable; Strings compare by
#     scalar values; structs, Lists and enums structurally), so replacing
#     the stored key with the equal key of the replacing call is an
#     equivalent program. The collection never does it (set's replacement
#     branch writes the value only); `stored-key-replaced` below would be
#     the mutant, and it survives every detector by construction.
#   * "probe stops at tombstone": the index holds no tombstone (removal is
#     a backward shift). The bug of that family here is a removal that
#     empties its slot without shifting the entries after it back, which
#     strands them behind an empty slot: no-backward-shift.
#   * "load threshold off by one" is the insertion rule's: one more entry
#     than 7/10 of the slots. No program observes it (the index never
#     fills), so its detector is the representation's own invariant
#     (tests/ordered-table.test's load bound).
