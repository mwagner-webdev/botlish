# Mutants of payload-bearing enum cases (audit/payload-enums/tools/mutate.tcl;
# PORTABILITY-PAYLOAD-ENUMS-MILESTONE-1.md): each a deliberate bug in one of
# the milestone's invariants -- nominal identity, case identity, payload
# comparison, hash composition, payload type admission, the construction's
# field rules, ownership transfer, cleanup, native tracing, the
# representation choices and the HIR text form.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ is a native
# mutant: mutate.tcl rebuilds the native backend for it. Lines starting with
# # outside an edit are comments.
#
# Not here, with the reason:
#
#   * the dynamic logical copy of a MutableVector held in a payload (the
#     `enum` case of core/mutvec.tcl's Share and runtime/mutvec.rs's
#     share_dynamic): a payload cannot be read back out of a value in this
#     milestone, so no program can observe whether its vector was shared or
#     copied -- the mutant would be equivalent until the matching milestone
#     reads payloads.
