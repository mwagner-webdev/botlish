# Mutants of parameterized structs and trait-constrained type slots
# (audit/trait-constrained-types/tools/mutate.tcl; TRAIT-CONSTRAINED-
# IMPRINTED-TYPES.md, "Mutation testing"): the mutants the milestone brief
# names, each a deliberate bug in the declaration of slots (hir/structs.tcl),
# the validity of an application (hir/structs.tcl's ApplicationProblem), the
# application's types (hir/types.tcl, hir/resolve.tcl), imprinting and the
# derived constraints (hir/imprint.tcl), trait satisfaction and the plan
# (hir/traits.tcl), specialization (hir/specialize.tcl), HIR text and
# compilation isolation (hir/format.tcl, hir/read.tcl, hir/declarations.tcl),
# the front-end cache (surface/cache.tcl) or the grammar
# (surface/parser.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit are
# comments.
