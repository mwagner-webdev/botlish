# Mutants of the declaration summaries (audit/declaration-summaries/tools/
# mutate.tcl; PARAMETERIZED-DECLARATION-SUMMARIES-MILESTONE-1.md, "Mutation
# testing"): each a deliberate bug in the framework (hir/summaries.tcl), in
# one migrated analysis (hir/callables.tcl, hir/types.tcl), or a return of
# the rejection or the unfolding the summaries replaced (hir/structs.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Lines starting with # outside an edit are comments.
#
# Not mutants (equivalent, and why):
#   * "an argument's contribution applied twice": every algebra's join is
#     idempotent (max of levels, union of sets), so applying a slot's entry
#     or a relevant argument's errors twice is the same program.
#   * "Bearing's unused `mutable` flag dropped": it decides nothing
#     (PARAMETERIZED-DECLARATION-SUMMARIES-MILESTONE-1.md, the census).
#   * "hash totality read from equality's summary": the two summaries are
#     equal by construction today -- core::value's `incomparable` and
#     core::hashing's `unhashable` list the same kinds, and the one form
#     whose answer differs by operation (a variable constrained by
#     Equatable, not Hashable) is only ever an argument, classified by the
#     operation's own Totality, never a probe. They stay two properties
#     because they are two operations.
