# Mutants of emission claims (audit/emission-claims/tools/mutate.tcl;
# EMISSION-CLAIMS-MILESTONE-1.md, "Mutation results"): one deliberate bug
# per rule a certificate rests on -- the checker's proof rules (the modular
# prototype's 34, ported), the recognizer outcome model, the value facts
# (hir/intset.tcl and the hir::range transfers it lifts, native result
# sets) and the trust boundary. Each is a way a certificate could be false.
#
#   @@ NAME DESCRIPTION
#   %% match PATTERN...         the tests run first (tcltest -match globs,
#                               over tests/emission-claims.test and
#                               tests/interval-sets.test)
#   ## FILE                     a file of the repository
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant every test of its `match` misses is run against both whole test
# files before it is reported as surviving.

# ---------------------------------------------------------------------------
