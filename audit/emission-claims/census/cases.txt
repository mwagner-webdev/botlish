# The modular census, under the compiler (EMISSION-CLAIMS-MILESTONE-1.md,
# "Differential and generated-program evidence"; MODULAR-EMISSION-PROOFS-
# MILESTONE-1.md, section 14): programs written to expose unsound or
# caller-dependent reasoning. Each claim is checked by the compiler, and its
# concrete truth searched for by running it (tools/witness.tcl) -- for a
# proven claim too: a counterexample to a certified claim is a false proof,
# and fails the census (tools/census.tcl).
#
#   @@ NAME DESCRIPTION
#   expect FN VERDICT           the compiler's verdict: proven, rejected,
#                               not-proved
#   prototype FN VERDICT        the modular prototype's (audit/emission-
#                               proofs): proven, disproven, not-proved
#   original FN VERDICT         the exploratory checker's (audit/emitter):
#                               proved, rejected, unused (with the case's
#                               own callers, which pass valid values only)
#   --- FILE                    a file of the case (main.bot is the entry;
#                               it is added beside the JSON workload)
#   ...
#   @@end
