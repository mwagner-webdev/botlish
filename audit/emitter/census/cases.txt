# Emitter mistakes (audit/emitter/tools/census.tcl;
# EMITTER-COROUTINE-EXPLORATION.md, "Correctness"): each applied alone to
# the emitter modules (audit/emitter/json), then checked by the emission
# checker in check_all.bot, and check_all.bot run on the interpreter with
# its outputs held to the oracle (tools/oracle.py) and to the unmutated
# program's outputs.
#
#   @@ NAME FILE EXPECT DESCRIPTION
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# EXPECT is the checker's expected verdict: the diagnostic kinds it must
# report (EMIT-..., comma-separated; it may report more: a mistake in a
# token emitter also breaks the claims of the emitters that call it), or
# `accepted` (none). The census fails when
# the checker's verdict differs, or a replacement does not apply.
#
# Most cases are mistakes. Some are not: an emitter whose output is correct
# but whose correctness the checker cannot prove (`imprecise`, the report's
# limits), or a mistake outside the guarantee (`semantic`: valid syntax, a
# wrong value; `structure`: a JSON text's nesting, which no regular
# language states), or an emitter that never completes (`vacuous`: it
# claims nothing). An accepted case's description starts with its category
# (census.tcl): `dynamic` (a run-time check the claim relies on fails),
# `failure` (the mistake, or bad data, makes the emitter fail), or one of
# the three above.
