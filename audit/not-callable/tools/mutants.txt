# The rule

@@ any-not-callable the rule takes a type of no fixed kind for a non-callable one: an `any` callee is rejected, never checked when the call runs
!! nc-dynamic-callee-runtime nc-rule-one-statement
## hir/types.tcl
<<<<
    return [expr {[kindOf $type] ni {"" block native coroutine}}]
====
    return [expr {[kindOf $type] ni {block native coroutine}}]
>>>>

@@ structs-callable a special case: a struct callee is left to the run-time check
