# The binding and signature dependency census of emission claims
# (EMISSION-BINDING-AND-SIGNATURE-DEPENDENCY-CENSUS-MILESTONE-1.md): paired
# programs in which a claimed function reads a value, a binding or a
# callable signature whose declaration holds an unresolved name, a
# diagnosed expression or a syntax hole -- and the valid programs beside
# them. tools/census.tcl compiles each one leniently and strictly, with the
# certificate memo and without it, through HIR interchange, and runs the
# runnable ones with their claims erased, judging the trace with the
# reference interpreter (tests/dfa-support.tcl).
#
#   @@ NAME DESCRIPTION
#   section TEXT              the report's section the case belongs to
#   class C                   the finding's consequence (the report's
#                             section 19): A wrong verdict in a rejected
#                             program, B missing certificate dependency,
#                             C accepted-program unsoundness, D precision
#                             loss, E correct, U undecided
#   observed VERDICT ...      each claim's verdict at the census's commit,
#                             in record order; `+` when it holds a
#                             certificate
#   appropriate VERDICT ...   what it should be (`undecided`: the report
#                             says why)
#   strict OUTCOME            `accepted`, or the kind a strict compilation
#                             raises
#   recover                   lenient compilation with syntax recovery
#   run INDEX JUDGMENT        the program, its claims erased, runs on every
#                             backend; its value is the claim INDEX's
#                             complete trace (a List of symbols), judged
#                             against that claim's recognizer: `ok` or
#                             `invalid`, the recorded judgment
#   --- FILE                  a file of the case (main.bot is the entry)
#   ...
#   @@end
#
#   @@sequence NAME DESCRIPTION   compilations in one process, the memo kept
#   step CASE VERDICTS REUSE      REUSE `reused` or `fresh` (the claims'
#                                 certificates taken from the memo or not);
#                                 `run INDEX JUDGMENT` after it judges a run
#   @@end
#
# The recognizer of every case: one ASCII digit.
