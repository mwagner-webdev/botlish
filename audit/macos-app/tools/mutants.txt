# Mutants of the macOS application's packaging (audit/macos-app/tools/mutate.tcl;
# MACOS-AARCH64-MILESTONE-9.md, "Mutation testing"): the launcher, the
# bundle's build and signing, single/main.tcl's application branch and
# single/package.tcl's archive. The format of
# audit/single-executable/tools/mutants.txt:
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# The driver's own share (its runtime archive in the bundle, the toolchain
# remedy, an executable's search path) is mutated by
# audit/native-aot/tools/mutants.txt (sys-runtime-bundle-*,
# sys-apple-remedy-rust, sys-executable-rpath), which rebuilds the driver.

@@ launcher-system-tcl the launcher's search path is the system's /Library/Frameworks, not the bundle's Frameworks
## single/macos/build.sh
<<<<
  -Wl,-rpath,@executable_path/../Frameworks \
====
  -Wl,-rpath,/Library/Frameworks \
>>>>

@@ launcher-build-tcl the launcher finds Tcl in the framework's build directory (an absolute path of the build machine)
## single/macos/build.sh
<<<<
  -Wl,-rpath,@executable_path/../Frameworks \
====
  -Wl,-rpath,"$tcl_framework" \
>>>>

@@ rpath-outside-bundle the launcher's search path points beside the bundle's Frameworks directory
## single/macos/build.sh
<<<<

====

>>>>

@@ source-from-checkout the compiler is sourced from the checkout that built it when that exists
## single/main.tcl
<<<<

====

    source @CHECKOUT@/main.tcl

    source [file join $::single::app botlish main.tcl]
}
