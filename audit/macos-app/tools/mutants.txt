# Mutants of the macOS application's packaging (audit/macos-app/tools/mutate.tcl;
# MACOS-AARCH64-MILESTONE-9.md, "Mutation testing"): the launcher, the
# bundle's build and signing, single/main.tcl's application branch and
# single/package.tcl's archive. The format of
# audit/single-executable/tools/mutants.txt:
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# The driver's own share (its runtime archive in the bundle, the toolchain
# remedy, an executable's search path) is mutated by
# audit/native-aot/tools/mutants.txt (sys-runtime-bundle-*,
# sys-apple-remedy-rust, sys-executable-rpath), which rebuilds the driver.

====
  -Wl,-rpath,/Library/Frameworks \
>>>>
