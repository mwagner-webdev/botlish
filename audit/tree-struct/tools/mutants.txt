# Mutants of tree structs and std::tree::walk
# (audit/tree-struct/tools/mutate.tcl; TREE-STRUCT-MILESTONE-1.md, "Mutation
# testing"): the families the milestone brief names, each a deliberate bug in
# the declaration's checks, its HIR text, the runtimes' equality, hashing and
# printing of a tree value, the totality walk, the program descriptor, the
# traversal (stdlib/tree.bot) or the typing that hands a walk's nodes over
# as the tree's own type.
#
#   @@ NAME DESCRIPTION
#   %% tests FILE ...      (optional) test files run first for this mutant
#   ## FILE
#   <<<<                   (or `<<<< all`: replace every occurrence, at
#   text to replace         least one; plain `<<<<` must occur exactly once)
#   ====
#   replacement
#   >>>>
#
# A mutant editing native/src/ is a native mutant: mutate.tcl rebuilds the
# native backend for it.
#
# Brief mutants with no non-equivalent mutant in this representation:
#
#   * "subtree node index participates in equality / hash": the chosen
#     representation has no node index or arena (a tree is a struct object
#     whose child List holds its children's objects), so the only physical
#     facts a walk could read are object addresses. The mutants
#     native-equality-reads-addresses and native-hash-reads-addresses read
#     them (the analog of an index), and the Tcl runtime has no address to
#     read at all.
