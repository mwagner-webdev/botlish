# Mutants of the C ABI type universe and callable imprinting
# (audit/c-abi-types/tools/mutate.tcl; C-ABI-TYPES.md): each a deliberate bug
# in the target table (core/cabi.tcl), the scalar registration
# (hir/sourcetypes.tcl), pointee and signature validation (hir/cabi.tcl), the
# type lattice and affinity (hir/types.tcl, hir/affine.tcl), the operations'
# registrations and implementations (core/cabi.tcl), argument admission
# (hir/range.tcl), imprinting (hir/imprint.tcl, hir/types.tcl) or the native
# C address word and its code (native/src/). The brief's mutants come first,
# then further ones.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant editing native/src/ is a native mutant: mutate.tcl rebuilds the
# native backend for it. Lines starting with # outside an edit are comments.

# --- the brief's mutants -----------------------------------------------------
