# Mutants of the static decision schedulers (audit/static-decisions/tools/
# mutate.tcl; STATIC-COMPILE.md, "Decision economics"): deliberate bugs in
# the batched scheduler (hir/static.tcl), its dependency analysis
# (hir/staticdeps.tcl), the reuse of method-call decisions
# (hir/static.tcl's MethodSeeds, hir/methods.tcl) and the demotion re-check's
# reuse of the check before it (hir::check, hir::signatures::infer's
# rounds; COMPILER-BOTTLENECKS.md 3.9), and in what a diagnostic
# prints that differs between builds (hir/semantic.tcl's SourceName and
# RefName, and every message naming a binding, a reference or a function by
# them). The first group changes what is decided (semantic); the second only
# how many builds it takes (economic: the milestone's contract is economic,
# so these are bugs too).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
