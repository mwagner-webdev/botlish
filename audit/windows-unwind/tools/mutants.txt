# Mutants of Windows unwind information and the native-frame GC roots built
# on it (audit/windows-unwind/tools/mutate.tcl; WINDOWS-X86-64-MILESTONE-3.md,
# section 7): the UNWIND_INFO encoder, the object's .pdata and .xdata, the
# JIT's function table, the collector's walk on Windows. (The stack-limit
# check and the call effects that went with it were removed by
# WINDOWS-X86-64-MILESTONE-4.md, and their mutants with them: the guard that
# replaced them is audit/native-stack's.)
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# The encoder's and the object's mutants apply on every x86-64 host
# (`%% linux-x86_64 windows-x86_64`): the Rust tests that detect them make
# Windows x86-64 code, which any x86-64 build can and an AArch64 build
# cannot (it has no x86-64 backend; on macOS and Linux AArch64 they are
# skipped). One that only Windows runs is `%% windows-x86_64`. Lines
# starting with # outside an edit are comments.
