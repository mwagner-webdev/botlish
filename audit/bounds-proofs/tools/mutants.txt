# Mutants of the bounds prover (audit/bounds-proofs/tools/mutate.tcl): the
# kill list of hir/completions.tcl's IndexBounds and its theorems --
# reduced indices (ReducedIndex: mod by the size, bit_and with the size
# minus one), guards on computed locals (RelationKey), the field-path size
# keys (hir/cardinality.tcl's ValueKey) and the length of a loop over a
# MutableVector (IterationLength) -- and of the rules they stand
# beside: the relational and range rules of IndexBounds, the size atoms, the
# per-check verdict (BoundsProven) and native lowering's use of it. Each is
# a deliberate bug that proves an index it may not, or stops proving one it
# should.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments. Update a mutant's text when the code it mutates changes,
# keeping it a mutant of the same rule.
