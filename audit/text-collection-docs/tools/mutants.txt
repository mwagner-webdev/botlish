@@ doc-static-type-unconditional encode_utf8's page states its List[std::byte::Byte] type unconditionally again, without the std::byte condition or the plain list
!! tcd-doc-utf8-static-type
## compilerpedia/notes/stdlib.notes
<<<<
Its static type depends, today, on what the compilation has loaded. When
the program has loaded std::byte -- an `import std::byte` in any of its
files, or an import of a module that loads it, such as std::abi::bytes --
it is List[std::byte::Byte]; otherwise it is the plain `list`, whose
elements the compiler knows nothing about. The values are the same either
way; only what the compiler can prove about them differs. So where an
element must be proven a Byte (a std::byte::Byte parameter, an index into
a 256-entry table, std::abi::bytes::from_list's List[std::byte::Byte]),
import std::byte or std::abi::bytes.
====
Its static type is List[std::byte::Byte], so it feeds
std::abi::bytes::from_list (the bytes a write(2) or a C call takes) and
ascii:: classification directly.
