# Mutants of the production event loop (audit/event-loop/tools/mutate.tcl;
# EVENT-LOOP-MILESTONE-1.md, "Mutation testing"): each a plausible bug in
# the scheduler (stdlib/event_loop.bot), the Linux driver's package
# (packages/event_loop_linux/event_loop_linux.bot) or its C adapter
# (packages/event_loop_linux/native/event_loop_linux.c), grouped by the rule
# it breaks -- the milestone's list: turn boundaries, observer starvation
# and duplication, skipped generation checks, stale queued delivery, timer
# order, lost wakeups, unbounded collection, Reliable-policy loss,
# inactive-source interference, incorrect shutdown, premature ownership
# release. Format (as audit/golden/tools/mutants.txt):
#
#   @@ NAME DESCRIPTION
#   %% TEST-PATTERNS        the detectors' tests to try first (mutate.tcl)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Every mutant must still apply and be killed by tests/event-loop.test or
# tests/event-loop-linux.test: a failed test, or a file that does not
# complete. The %% line names the tests of the rule the mutant breaks
# (tcltest -match patterns of either file), run first; a mutant they do not
# kill runs both files whole before it counts as surviving. A mutant keeps
# its program warning-free (the scenarios compile with -warnings error), so
# a kill is a behavior's, never a warning's.
