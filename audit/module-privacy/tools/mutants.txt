# (No mutant removes the resolver's own check of a qualified reference
# (hir/resolve.tcl's ResolveQualifiedRef): it is the second line behind the
# loader, which rejects every reference a source file writes first, and no
# source program reaches it -- the build itself makes qualified references
# only for planned trait and context-trait calls, whose implementations
# conformance already requires to be public (trait-private-implements,
# context-trait-private-implements). A mutant of it is equivalent; the
# check's effect shows when the loader's is mutated away (rooted-lookup-
# ignored), and mp-access-message tells the two apart by the related
# location only the loader gives.)
