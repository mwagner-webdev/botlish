# Mutants of the List length refinement (audit/list-length-refinement/tools/
# mutate.tcl; LIST-CARDINALITY-REFINEMENTS.md): deliberate bugs in the
# schema's exact order, the refinement's resolution, subtyping and admission,
# decay, joins, the sources that mint it (literals, the empty List,
# list::append, collecting loops, copies of fixed arrays, guards,
# list::with_length), the boundaries that forget it (undeclared results,
# semantic instance keys, mutable element contracts, handlers), the proofs
# that read it (bounds, extents, list::length), HIR text and interchange,
# FIXED-ARITY-LIST-RETURN, and the native validator.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/ is a native
# mutant: mutate.tcl rebuilds the native backend for it. Lines starting with
# # outside an edit are comments.
