# Mutants of the native stack guard (audit/native-stack/tools/mutate.tcl;
# MACOS-AARCH64-MILESTONE-4.md, "Mutation testing"): the host's stack
# discovery (native/src/runtime/platform/linux.rs, macos.rs), the shared
# guard (platform/guard.rs), the publication of the running stack on
# coroutine switches (runtime/coroutine.rs) and the bounds the collector's
# frame walk reads (runtime/vm.rs).
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant with no %% line applies on every host with the guard. One whose
# code a host never compiles (platform/macos.rs on Linux) is skipped there,
# never counted as killed. Lines starting with # outside an edit are
# comments.
