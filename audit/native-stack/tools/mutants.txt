# Mutants of the native stack guard (audit/native-stack/tools/mutate.tcl;
# MACOS-AARCH64-MILESTONE-4.md, "Mutation testing";
# WINDOWS-X86-64-MILESTONE-4.md, "Mutation testing";
# WINDOWS-X86-64-MILESTONE-5.md, "Tests": Windows' coroutine fibers, their
# guarantees and their publication): the host's stack
# discovery (native/src/runtime/platform/linux.rs, macos.rs, windows.rs),
# the POSIX guard (platform/guard.rs) and the Windows guard
# (platform/windows.rs), the drivers that install them (main.rs,
# runtime/aot.rs), the publication of the running stack on coroutine
# switches (runtime/coroutine.rs), the bounds the collector's frame walk
# reads (runtime/vm.rs), and what the guard lets the compiler leave out:
# the depth reservation of native-frame functions (codegen/roots.rs), the
# call effects of a Botlish call (nir.rs) and the stack probes that keep a
# large frame from stepping over a guard (codegen/mod.rs).
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant with no %% line applies on every host with the guard. One whose
# code a host never compiles (platform/macos.rs on Linux, guard.rs on
# Windows) is skipped there, never counted as killed. Lines starting with #
# outside an edit are comments.
