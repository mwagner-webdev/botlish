# Mutants of the http package and its provider (audit/http-client/tools/mutate.tcl,
# HTTP-CLIENT-PACKAGE-MILESTONE-1.md, "Mutation testing").
#
#   @@ NAME DESCRIPTION
#   %% TESTFILE:PATTERN[,PATTERN...]...   tests (a tcltest -match each) that must kill it
#   !! COMMAND                            a tool (run in the mutant's tree) that must fail
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Lines starting with # outside an edit are comments. A mutant of the
# native unit (packages/http/native) rebuilds the test unit in the mutant
# tree's own cache; nothing reaches the checkout's.
