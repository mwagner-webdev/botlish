# mutants.txt -- the syntax-recovery mutants (tools/mutate.tcl;
# SYNTAX-RECOVERY-MILESTONE-1.md, "Mutation testing").
#
# Format: "@@ NAME DESCRIPTION" starts a mutant; "%% FILE ?PATTERN...?"
# names the test file that states its rule (tests/syntax-recovery.test when
# absent) and the tests of it that state it (tcltest -match patterns; every
# test when absent); "## FILE" names the file its next edits change; each
# edit is "<<<<", the exact text to replace (occurring once), "====", its
# replacement, ">>>>". Update a mutant's text when the code it mutates
# changes, keeping it a mutant of the same rule.
#
# Two candidates are left out as equivalent mutants: no program observes
# them, because every check skips a poisoned value and a hole is poison --
# a hole's range taken as no value at all (hir/range.tcl's hole case), and a
# semantic instance of a function whose body holds a hole (the call is typed
# by the declared result, or poison when there is none, either way). Both
# guards stay, for checks that may one day read those facts.
