# Mutants of UTF-16LE on byte storage (audit/abi-bytes/tools/utf16-mutate.tcl;
# UTF16-BYTE-STORAGE-MILESTONE-1.md, "Mutation testing"): deliberate breaks
# of the codec's contract, in the Tcl backends' implementation
# (core/utf16text.tcl) and the native runtime's (native/src/runtime/ops.rs).
# Each must be killed, and by the detector its `!!` line names -- the test
# (or the Rust test, `rust:NAME`, or the fuzzer, `fuzz`) that checks the
# contract the mutant violates; a mutant killed only by something else is
# reported as such and counted as a failure.
#
#   @@ NAME DESCRIPTION
#   !! DETECTOR ...
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# The path-level mutants (the Win32 terminator, a terminator in a native
# path, normalized path text, lossy text, a surrogate replaced on open) are
# audit/filesystem/tools/mutants.txt's.

# The NUL-unit measure (std::byte_store::utf16le_units_before_nul: how
# std::windows::fs measures a listed name). Swapping the bytes of a pair is
# no mutant of it -- a unit is 0 exactly when both its bytes are, in either
# order -- so the byte-order mutants are of what the order does decide: the
# pairing (a single 00 byte, or 00 00 across two units, is no terminator).

@@ rust-nul-single-byte the native measure stops at a unit whose low byte is 0 (a single 00 byte): U+0100 or U+2E00 ends a name
