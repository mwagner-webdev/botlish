# Mutants of MutableArray[T] as a value (audit/mutable-array/tools/mutate.tcl;
# MUTABLE-ARRAY.md): the mutants the milestone brief names (item 57), each a
# deliberate bug in the affinity query (hir/types.tcl), the specialization
# key (hir/specialize.tcl), the ownership analysis (hir/affine.tcl), the
# place and copy-on-write elaboration (hir/mutvec.tcl), the ownership roles
# of the registrations (core/mutarray.tcl, core/native.tcl), the Tcl runtime
# (core/mutarray.tcl, core/mutvec.tcl, core/affine.tcl) or the native
# runtime (native/src/runtime/ops.rs, mutvec.rs, affine.rs, native/lower.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
#
# Brief mutants with no separate non-equivalent mutant in this
# representation:
#
#   * "native repeated constructor bypasses affinity": the duplication
#     check is static and backend-independent -- every backend compiles the
#     one HIR the ownership discipline accepted (create of an affine value
#     never reaches a native runtime). Its two mutants are
#     create-accepts-affine (the registration's role) and
#     signature-ignores-repeat (the discipline ignoring the role).
#   * "copy becomes eager O(N)" on the Tcl backends: a Tcl list is itself a
#     copy-on-write value, so an eager copy there is unobservable but for
#     time; the native mutant (copy-eager-deep-native) is the one the
#     copy-on-write counters observe.
