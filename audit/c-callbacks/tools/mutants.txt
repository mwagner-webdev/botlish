# Mutants of synchronous C callbacks (audit/c-callbacks/tools/mutate.tcl;
# C-CALLBACK-MILESTONE-1.md): each a deliberate bug in the front end's
# checks (hir/callbacks.tcl, hir/foreign.tcl), native lowering, the C side
# (native/src/codegen/callback.rs, clif.rs, fusion.rs) or the runtime
# (native/src/runtime/callback.rs, vm.rs). The brief's mutants first
# (section 13: root retention, convention, raw bits, activation, thread,
# actor, rooting of suspended frames, result conversion, non-retention,
# re-entry depth, error and yield propagation), then further ones.
#

#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
