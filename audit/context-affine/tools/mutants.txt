# Mutants of context-owned affine state
# (audit/context-affine/tools/mutate.tcl; CONTEXT-OWNED-AFFINE-STATE-
# MILESTONE-1.md, "Mutation testing"): each a deliberate bug in the
# installation's ownership role (core/contexts.tcl), the context places of
# the ownership analysis (hir/affine.tcl), the element places and the
# share descriptors (hir/mutvec.tcl, core/mutvec.tcl, core/native.tcl) or
# the native context slots (native/lower.tcl).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. Lines starting with # outside an edit
# are comments.
#
# Not a mutant, and why: "the context-trait plan copies the installed
# state". The plan binds no context value at all -- a clone's trait
# parameter disappears and each operation becomes a direct call of the
# implementation, which loads its own context parameter
# (tests/context-affine.test's cao-trait-plan-no-state-copy checks the
# monomorphized HIR) -- so there is no copy to make; a plan that passed the
# installed value would be a new code path, not a one-line slip. Nor is "a
# private helper bypasses affinity": privacy has no ownership code path (a
# private function is analyzed exactly like a public one); the helpers of
# cao-helpers-wrappers-traits are covered by every mutant below.
