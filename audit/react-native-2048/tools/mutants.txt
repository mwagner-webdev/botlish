# Mutants of the React Native integration (audit/react-native-2048/tools/
# mutate.tcl; BOTLISH-REACT-NATIVE-2048-PACKAGE-MILESTONE-1.md, "Mutation
# testing"): each a deliberate defect in the generator, in what it generates
# (the C++ core, the TurboModule, the TypeScript entry point, CMake), in the
# app's hook, or in what keeps the package Android's and the library's own.
#
#   @@ NAME DESCRIPTION
#   !! TEST ...        the tests of tests/react-native-package.test meant to
#                      detect it (one failing is a kill)
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# Lines starting with # outside an edit are comments.
