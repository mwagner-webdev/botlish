# Mutants of enums (audit/enums/tools/mutate.tcl; ENUMS.md): the mutants the
# milestone brief names, each a deliberate bug in the type lattice
# (hir/types.tcl), case resolution (hir/resolve.tcl), the declarations
# (hir/enums.tcl), admission (hir/range.tcl), the HIR text form
# (hir/format.tcl, hir/read.tcl), struct scalar replacement (hir/escape.tcl),
# the Tcl runtime (core/value.tcl, core/hashing.tcl, core/primitives.tcl),
# native lowering (native/lower.tcl) or the native runtime and code generator
# (native/src/runtime/ops.rs, native/src/codegen/clif.rs).
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
#
# Brief mutants with no separate non-equivalent mutant in this
# representation:
#
#   * "reordered declaration changes semantic equality", read as equality by
#     (enum identity, case position): positions are unique within one
#     declaration, so within one program that equality is exactly equality
#     by (enum identity, case name) -- an equivalent mutant. The
#     non-equivalent readings are here: equality by position alone
#     (equal-by-ordinal-tcl, which a reordering changes) and hashing by
#     position (hash-uses-position-*, which a reordering changes).
