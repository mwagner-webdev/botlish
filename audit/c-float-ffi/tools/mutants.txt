# Mutants of C float and C double across the FFI (audit/c-float-ffi/tools/
# mutate.tcl; C-FLOAT-FFI-MILESTONE-1.md): each a deliberate bug in the type
# model, the boundary rules (core/cabi.tcl, native/src/runtime/value.rs, the
# generated code of native/src/codegen/clif.rs), the layouts or the static
# decisions. The brief's mutants first, then further ones. (The binding
# generator's float/double swaps are audit/c-bindgen/tools/mutants.txt's:
# bindgen-float-as-double, bindgen-double-as-float, bindgen-long-double-as-
# double, bindgen-float-width-carrier, layout-float-as-integer.)
#

#   ## FILE
#   <<<<

#   >>>>
