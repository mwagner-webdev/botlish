# Mutants of the process_linux package (audit/process-linux/tools/mutate.tcl;
# PROCESS-LINUX-PACKAGE-MILESTONE-1.md, "Mutation testing"). The census's 15
# (audit/managed-subprocess/tools/mutants.txt) ported to the package, and
# the package's own.
#
#   @@ NAME DESCRIPTION
#   %% TESTFILE:PATTERN[,PATTERN...]...   tests (a tcltest -match each) of which one must fail
#   ## FILE                               relative to the repository root
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A test that hangs is killed by its own watchdog (timeout) and fails: a
# hang is a detection, never a pass. A mutant killed only because the test
# could not set up (the adapter or a scenario program does not compile:
# every build is -Werror, so a mutant must leave no variable unused) is no
# detection: the harness reports it NOT-BUILT.
