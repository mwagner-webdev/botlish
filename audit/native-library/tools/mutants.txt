# Mutants of native libraries (audit/native-library/tools/mutate.tcl;
# NATIVE-LIBRARY-MILESTONE-1.md, "Mutation results"): export roots
# (hir/specialize.tcl), the export checks (hir/exports.tcl), the library
# build and its checks (native/library.tcl), the error table
# (native/lower.tcl), the trampolines (native/src/codegen/library.rs), the
# runtime ABI (native/src/runtime/library.rs) and the program record
# (native/src/runtime/program.rs).
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant with no %% line applies on every host that builds libraries.
# Lines starting with # outside an edit are comments.
#
# Not here, because it is equivalent: ProgramScope's drop not restoring the
# thread's previous program (runtime/library.rs). A call sets its program
# for itself, which is needed (create leaves the thread's program as it
# found it), but the restore matters only when two programs share one
# runtime copy, as the driver's JIT runs them. A library never does: its
# runtime is a private copy with its own thread-local, so a call of another
# library inside a call (nl-nested-libraries) cannot reach it either way.
