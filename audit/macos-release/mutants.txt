# Mutants of the macOS release pipeline (ICY-TOWER-MACOS-APP-MILESTONE-1.md,
# "Credential-validation mutation testing"; audit/macos-release/tools/
# mutate.py): each a plausible defect of the credential preflight
# (credentials.py), the release's stages (release.py), the bundle's checks
# (bundle.py, package-macos.sh) or the workflow's trust boundary, in the
# repository's mutant format, with the tests that must kill it:
#
#   @@ NAME DESCRIPTION
#   !! TEST ...                      FILE.CLASS.METHOD of audit/macos-release/tests/
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant is killed only by a named test failing: the test that states the
# rule the mutant breaks, never an unrelated failure.
