# Mutants of Hashable, the total lowerings and the private table hash
# (audit/hashable/tools/mutate.tcl; HASHABLE-AND-KEYED-HASH.md, "Mutation
# testing"): the mutants the milestone brief names, each a deliberate bug in
# the witness predicate (hir/types.tcl, hir/traits.tcl), the hashes'
# admission (hir/range.tcl), the visibility boundary (surface/modules.tcl,
# hir/internal.tcl, core/hashing.tcl's registration), native lowering
# (native/lower.tcl), or the hashes themselves (core/hashing.tcl,
# native/src/runtime/ops.rs). A runtime defect of both implementations is
# two mutants, one per runtime.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.
