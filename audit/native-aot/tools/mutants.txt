# Mutants of native executable emission (audit/native-aot/tools/mutate.tcl;
# MACOS-AARCH64-MILESTONE-5.md, "Mutation results"): the hosts that link
# executables and C calls (native/src/codegen/aot.rs), the program object's
# target (codegen/mod.rs), its runtime imports (codegen/clif.rs), the rustc
# link, the generated startup and the standalone runtime
# (runtime/aot.rs), the output path and the host check (codegen/target.rs).
#
#   @@ NAME DESCRIPTION
#   %% HOST ...        (optional) the host targets the mutant applies to
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant with no %% line applies on every host that links executables.
#
# Not here, because it is equivalent: the ELF context-area relaxation
# (codegen/mod.rs's context_relocations) without its ELF magic check. On
# Linux every object is ELF; a Mach-O object read as ELF has zeros where ELF
# keeps its section headers' offset and count (0x28, 0x3c: inside the first
# LC_SEGMENT_64's empty segment name and its vmaddr), so no section is found
# and nothing is rewritten (MACOS-AARCH64-MILESTONE-5.md, "Mutation results").
# One that changes nothing a host compiles (macOS's gate on Linux) is
# skipped there, never counted as killed. Lines starting with # outside an
# edit are comments.
