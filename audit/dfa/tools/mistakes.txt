# Mistakes in json_lex.dfa (audit/dfa/tools/mistakes.tcl;
# DFA-COROUTINE-EXPLORATION.md, "Static guarantees"): realistic errors of a
# recognizer's author, each applied alone. KIND is what the mistake breaks:
#
#   structure  the declaration as an automaton (determinism, reachability,
#              acceptance, names): what the front end can rule out
#   boundary   where a token ends, or what the end of the input means
#   progress   a move that consumes nothing
#   alphabet   bytes, characters and Unicode scalar values confused
#   grammar    a well-formed automaton for the wrong language
#
#   @@ NAME KIND DESCRIPTION
#   <<<<
#   text to replace (must occur exactly once in json_lex.dfa)
#   ====
#   replacement
#   >>>>

        digit -> integer
>>>>
