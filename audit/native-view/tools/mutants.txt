# Mutants of read-only native layout views (audit/native-view/tools/mutate.tcl;
# NATIVE-LAYOUT-VIEWS.md): each a deliberate bug in pointer-field
# declaration (hir/layouts.tcl), the NativeView type (hir/types.tcl,
# hir/cabi.tcl, hir/affine.tcl), the operand checks and elaboration
# (hir/layouts.tcl), the Tcl backends' refusal (core/binary.tcl), native
# lowering (native/lower.tcl) or the native runtime
# (native/src/runtime/nview.rs, ops.rs) -- the brief's defects first, one per
# layer where a layer implements the rule separately, then further ones.
#
#   @@ NAME DESCRIPTION
#   ## FILE
#   <<<<
#   text to replace (must occur exactly once in FILE)
#   ====
#   replacement
#   >>>>
#
# A mutant may have several edits. A mutant editing native/src/ or the
# native crate's manifest is a native mutant: mutate.tcl rebuilds the native
# backend for it. Lines starting with # outside an edit are comments.

# --- field offset ignored / read from offset zero ------------------------

@@ offset-ignored-lowering native lowering reads every field of a view at the view's (folded) base, ignoring the field's own offset
## native/lower.tcl
<<<<

====
    return [NativeRepr fn $e $view [lrange $field 2 end] $base]
>>>>

# --- no copy through Bytes ------------------------------------------------------

@@ copy-per-read every field read through a view first makes a byte storage of the field's offset (an allocation per read)
